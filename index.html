Vehicle Re-Identification & Visual Search Engine

Deep metric learning pipeline matching vehicle entry and exit records across non-overlapping highway cameras when license plates are obscured, missing, or unreadable.

  • Microservice Architecture: Packaged the pipeline as a FastAPI microservice with automated memory cleanup for sliding time windows.
