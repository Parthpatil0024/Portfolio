Deep Learning · OSNet · FAISS Vector DB

Vehicle Re-Identification & Visual Search Engine

Deep metric learning pipeline matching vehicle entry and exit records across non-overlapping highway cameras when license plates are obscured, missing, or unreadable.

  • 512-D Visual Feature Extraction: Deployed an OSNet (IBN 1.0x) deep Re-ID model producing visual embeddings, quantized with OpenVINO FP16 for real-time CPU inference.
  • Time-Bucketed Vector Search: Built 4-hour temporal FAISS vector indices with cosine similarity search, matching vehicle records across 1,000+ daily transits in under 45ms.
  • Multi-Modal Re-Ranking: Combined plate OCR, vehicle color histograms, and windshield cues (FASTag placement, stickers) to achieve 92% top-1 match accuracy, reducing manual audit reviews by 80%.
  • Microservice Architecture: Packaged the pipeline as a FastAPI microservice with automated memory cleanup for sliding time windows.
